## D-019: CI matrix early, signing and auto-update deferred

- **Status**: accepted
- **Date**: 2026-07-30
- **Context**: The app is for personal use now with distribution intended
  later. Signing costs money and time; cross-compilation breakage is
  architectural and gets exponentially more expensive to discover late,
  especially since D-002's pure-Rust driver stack only stays pure if something
  proves it.
- **Decision**: A build-only CI matrix across macOS arm64 + x86_64, Windows
  x64, and Linux x64 from early on, publishing unsigned artifacts. No Tauri
  updater in v1. Add Apple Developer ID signing and notarization, and Windows
  code signing, at the point the app is first handed to another person -- not
  before. AppImage as the Linux default given webkit2gtk 4.1's variable
  availability across distros.
- **Rationale**: The asymmetry is the whole argument: signing is a chore
  purchasable at any time, whereas a transitive C dependency breaking the
  Windows build is something to learn at commit 50 rather than commit 5000.
  "Distribute later" postpones the cross-platform obligation, it does not
  cancel it. Two platform facts follow and constrain other work: WebKitGTK is
  the compatibility floor for all UI work since Tauri uses the OS webview, and
  Linux packaging is the awkward target.
