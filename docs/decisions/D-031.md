## D-031: Instrument-panel visual direction for the UI overhaul

- **Status**: accepted
- **Date**: 2026-11-06
- **Date superseded**:
- **Date deprecated**:
- **Date promoted**:
- **Context**: The stated ask for the UI overhaul is "a futuristic, striking
  UI". D-023 fixes the stack (Tailwind v3 + shadcn, hsl custom properties)
  and the WebKitGTK 4.1 CSS floor, which `check-css-floor` enforces: no
  `color-mix()`, `oklch()`, `:has()`, `@property` or container queries. The
  webview CSP is `default-src 'self'` (T-021), so no font can be fetched
  remotely. The product lives in a dense, virtualized result grid (D-010)
  that people use for hours. T-091 turns the ask into specifics once, so the
  look is not re-argued per component in T-092 to T-096.
- **Decision**: The **instrument-panel** direction. Futuristic through
  precision and restraint, not decoration.
  (1) **Theme**: dark is the default and the design target. Light is a
  maintained secondary token set, switchable in settings or by following the
  OS.
  (2) **Palette (dark / light)**: base `#0B1018` / `#F6F8FB`, panel
  `#111826` / `#FFFFFF`, raised `#172033` / `#EEF2F7`, text `#E6EDF7` /
  `#0E1726`, muted text `#8A99B3` / `#55627A`, one accent, electric cyan
  `#22D3EE` / `#0E7490`. Status hues are reserved per D-032. Syntax
  highlighting has its own desaturated set (keyword steel-blue, string
  rose, number sand), outside both the accent and the status hues, so code
  never reads as a status. Every text
  colour is at least WCAG AA (4.5:1) on every surface in both themes
  (checked 2026-11-06).
  (3) **Typography**: Inter for UI chrome and JetBrains Mono for data cells,
  the query editor, identifiers and numbers (tabular numerals). Both are
  OFL-licensed and bundled as local variable `woff2` (about 300 KB). No
  system-font fallback is designed for, and no third display face.
  (4) **Surface and depth**: depth comes from three luminance steps (base,
  panel, raised) separated by 1px hairline borders at low alpha
  (`hsl(var(--x) / α)`). Glow (a 1px cyan ring plus a soft outer
  `box-shadow`) appears only on focus, the selected row or cell, and the
  active tab; nothing glows at rest. Drop shadows only on floating layers
  (menus, dialogs, toasts). `backdrop-filter` is never used. Corner radius is
  4px.
  (5) **Density**: compact by default (28px grid and tree rows, 13px UI text,
  12.5px mono data). One Comfortable option sets 34px rows through a single
  `--row-h` variable that affects only grid and tree rows.
  (6) **Motion**: only to report a change of state. Hover, focus and glow
  fade over 120ms ease-out; overlays and panels enter over 160 to 200ms.
  Only `opacity` and `transform` animate. Data never animates: no row
  fade-in, no cell flashes, no motion in virtualized scroll, nothing looping
  at rest. The one exception is a thin cyan scan line while a query runs.
  `prefers-reduced-motion` sets every transition to 0 and replaces the scan
  line with a static "Running…" label.
  (7) **Mock**: a static HTML mock of the main workspace using exactly these
  tokens is kept at `docs/design/workspace-mock.html` and is the reference
  T-092 to T-096 implement against.
- **Rationale**: Glass/aurora was the most dramatic option, but it depends on
  `backdrop-filter` and large gradients, which are the expensive path on
  WebKitGTK's Linux compositor and fight legibility in a data grid. Neon
  terminal was striking but tiring over long sessions and too narrow a
  palette for D-032's status semantics. The instrument panel gets its "wow"
  from things that cost nothing at the floor: a near-black field, one
  saturated accent, hairline geometry and monospace data, with glow saved
  for the moment of interaction so it stays meaningful. Bundled fonts are
  forced by the CSP and give the same look on every OS. Fonts vary most on
  Linux, the platform the floor already constrains. Compact density and
  data-free motion follow from what the tool is for: rows per screen and
  calm over hours. Owner chose the recommended option on every branch
  (challenge-me, 2026-11-06).
