## D-025: Rename off drizzle-studio; permissive license

- **Status**: accepted
- **Date**: 2026-07-30
- **Context**: The project directory is currently `drizzle-studio`, which is
  the name of Drizzle's existing product, and D-019 records an intent to
  distribute later. Recorded as a tentative default.
- **Decision**: Choose a distinct project name before any distribution and
  rename the repository accordingly; do not ship under `drizzle-studio` or a
  close variant. License under MIT or Apache-2.0.
- **Rationale**: Using another project's product name invites trademark
  confusion and makes the tool look like an official Drizzle artifact, which is
  a problem the moment it leaves this machine -- and renaming later costs more
  than renaming now. A permissive license matches the personal-tool scope in
  D-011 while leaving distribution open.
