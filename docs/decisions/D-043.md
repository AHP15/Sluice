## D-043: Typed, closed per-engine connection options, with a pinned TLS trust anchor and client identity

- **Status**: accepted
- **Date**: 2026-11-07
- **Date superseded**:
- **Date deprecated**:
- **Date promoted**:
- **Context**: D-042 gave TLS a `tls_ca_file` defined as an anchor *added to*
  the system trust store. libpq's `sslrootcert` and Mongo's `tlsCAFile` — the
  parameters it is mapped from — *replace* the trust store, which users rely
  on to pin an internal CA; mapping them onto an additive anchor lets any
  publicly trusted CA vouch for the hostname (R-059). The rest of D-042 stands.
- **Decision**: `Target` gains `options: EngineOptions`, an enum with one
  closed, typed variant per engine (`Postgres{..}`, `Sqlserver{..}`,
  `Mongodb{ replica_set, auth_source, .. }`); each driver receives only its own
  variant, stored as a closed `[profile.<engine>]` sub-table whose unknown keys
  are errors, validated at load. TLS gains engine-neutral trust and identity
  settings alongside the `tls` mode: `tls_ca_file` **replaces the trust store
  for that connection** — only certificates chaining to that file verify,
  matching libpq and Mongo semantics — and `tls_client_cert` /
  `tls_client_key` (file paths), mapped from the engines' URL spellings. An
  encrypted client key is refused until a D-008 credential provider can supply
  its passphrase; key material never enters the profile file, only its path.
  Settings that would override a settled guarantee are never options: pool
  size (D-028), TLS weakening beyond the `tls` mode (D-007),
  `directConnection` (D-040 decides it), and `readPreference`. Options are
  non-secret and may be logged in shape per D-020.
- **Rationale**: A CA file supplied for a connection is a statement of whom to
  trust, and every engine's own client reads it as exclusive; honouring it
  that way keeps users on `Verify` without silently widening trust to every
  public CA. Replacing rather than adding costs nothing for managed databases,
  whose bundles already contain the chain they need.
- **Supersedes**: D-042
