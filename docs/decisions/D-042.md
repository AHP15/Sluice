## D-042: Typed, closed per-engine connection options, with TLS trust anchors and client identity

- **Status**: superseded
- **Date**: 2026-11-07
- **Date superseded**: 2026-11-07
- **Date deprecated**:
- **Date promoted**:
- **Context**: D-033 gave `Target` closed, typed per-engine options and
  deliberately kept TLS to the existing `tls` mode key. Red-teaming found that
  leaves no home for a custom CA bundle or client certificate (Mongo
  `tlsCAFile` / `tlsCertificateKeyFile`, libpq `sslrootcert` / `sslcert` /
  `sslkey`): Amazon RDS and DocumentDB chain to CAs outside OS trust stores,
  so under the default `Verify` they cannot connect, and the only escape is
  `accept_invalid_certs`, the weakening D-007 makes exceptional (R-051).
- **Decision**: `Target` gains `options: EngineOptions`, an enum with one
  closed, typed variant per engine (`Postgres{..}`, `Sqlserver{..}`,
  `Mongodb{ replica_set, auth_source, .. }`); each driver receives only its own
  variant, stored as a closed `[profile.<engine>]` sub-table whose unknown keys
  are errors, validated at load. TLS gains engine-neutral **trust and
  identity** settings alongside the `tls` mode: `tls_ca_file` (an extra trust
  anchor, added to — never replacing verification) and `tls_client_cert` /
  `tls_client_key` (file paths), mapped from the engines' URL spellings. An
  encrypted client key is refused until a D-008 credential provider can
  supply its passphrase; key material never enters the profile file, only
  its path. Settings that would override a settled guarantee are never
  options: pool size (D-028), TLS weakening beyond the `tls` mode (D-007),
  `directConnection` (D-040 decides it), and `readPreference`. Options are
  non-secret and may be logged in shape per D-020.
- **Rationale**: A trust anchor strengthens verification rather than
  weakening it, so giving it a typed home is what keeps users of managed
  databases on `Verify` instead of pushing them to `accept_invalid_certs`.
  The rest of D-033's reasoning stands: a free-form map or a stored URL would
  let any profile silently break the budget, TLS or write routing.
