- **Notes**: Run against `mongo:7` in Docker as a single-node replica set (a
  standalone mongod cannot open a transaction). All four scenarios executed end
  to end against heterogeneous documents. 20 findings recorded: 5 HELD, 7
  STRAINED, 8 BROKE. R-029's bar — that the exercise produce findings rather
  than confirmation — is met. The navigator tree's driver-declared node kinds
  (T-008) held cleanly; the breaks concentrate in the value/column model:
  `Rows.columns` presumes a catalog Mongo lacks, `ColumnDesc` declares one type
  per column where Mongo has one per value (observed `qty` holding 3 BSON types
  in a single page), `WireValue` has no document/array variant, and the outcome
  *sequence* is permanently length 1 because Mongo has no multi-statement
  script. R-009 and R-026 were both reproduced live. Six recommended contract
  changes for T-005 are listed in FINDINGS.md; items 1-3 touch T-016/T-010 and
  are cheap now, expensive once the Postgres driver ships against the
  scalar-only shape.
