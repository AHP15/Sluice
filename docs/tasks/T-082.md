## T-082: SQL Server browse compilation, lossless type encoding, and core filters

- **Status**: done
- **Size**: L
- **Implements**: D-005, D-006, D-010, D-029

- **Acceptance**: Structured browse compiles to parameterised T-SQL with keyset or declared OFFSET/FETCH paging, every core filter operator binds its values as parameters, and each SQL Server type reaches the wire losslessly — `MONEY` via `CONVERT(VARCHAR, col, 2)`, exact numerics as `Numeric` text, unknown types as `Unsupported` — under the per-value size ceiling.

- **Notes**: T-048 (per-relation keyset arity, R-010) verifies the composite-key plan against this driver. Built: the projection is written per catalog-declared type (never `SELECT *`), so `sql_variant` (`CONVERT(nvarchar(4000), …)`), CLR types incl. `geography`/`hierarchyid` (`.ToString()`) never reach tiberius's panicking decoder and surface as `Unsupported`; an unknown type is never selected (only its NULL-ness). `money`/`smallmoney` and `decimal` cross as `Numeric` text, `bigint` as `Numeric`, temporals as ISO-8601 (style 126). Ceiling applied in SQL via `DATALENGTH` (Oversized, `handle: None` until value fetch exists). Bound parameters cast to *widened* targets (bigint, `decimal(38, s')`, `datetime2(7)`), except `datetime` (bound as itself, because of its 1/300 s ticks) and varchar keyset cursors (`varchar(max)`, so cursor comparisons follow the column's sort order); a decimal value with more scale than the bind target holds is refused instead of rounded. `browse_batches` streams with credit and closes the connection on a mid-page stop. Edit gate is read-only until T-085. Live test ran against SQL Server 2022 (container): 11/11.
