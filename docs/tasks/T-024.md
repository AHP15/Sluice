- **Notes**: Structural half already held (T-022/T-028): connection URLs are
  decomposed with the password as `Secret`, and display forms are rebuilt
  from components. Added the defence-in-depth pass, `sluice_core::Redactor`,
  holding the session's password: it walks `message`, payload message, every
  payload `extra` pair (detail, hint, where, and now the `source()` chain as
  `cause.N`), and hint strings; matches raw, percent-encoded (both hex cases,
  `+` for space), backslash-escaped, quote-doubled and JSON-escaped forms; a
  password split across adjacent fields; and a long-enough prefix truncated at
  a field end. `redact_shapes` handles passwords nobody told us about
  (`scheme://user:pass@`, `password=`/`pwd=` in conninfo/ODBC form, including
  a conninfo quoted inside a SQL literal). Applied at: the driver's lease path
  (incl. pool-acquire errors) and connect; every error *outcome* in a script
  result; the app's session commands after the panic guard (so a caught panic's
  text meets the session's password); the panic guard's detail and the crash
  file (shapes); a failing config's message in the launcher (shapes). The old
  `error_map::redactable` stopgap is gone. **Found and fixed by the corpus:**
  (1) `error_map` put the raw driver text in `payload.message`, which reaches
  the webview — an unredacted copy beside the redacted one; (2) a failing
  statement's error rides inside an `Ok` result, so boundary-only redaction
  missed it — the engine echoed the password verbatim in both fields; (3) the
  pool wrapper hid the server's error, so a wrong password surfaced as a bare
  "connection failed" with no detail — now unwrapped; (4) **TLS downgrade:**
  `TlsMode::Verify` connected in plaintext to a TLS-less server, because
  tokio-postgres's default `sslmode` is `Prefer` — now `Require`, with an
  actionable message ("add `sslmode=disable` for a local server"). The live
  corpus (`redaction_corpus.rs`, in the CI Postgres gate) uses a role whose
  password is hostile (`p@ss w:rd/'é"x`) and asserts no encoding of it in the
  JSON or Debug of five real shapes: bad password, engine echo, TLS failure,
  DNS failure, driver panic. Residual: a crash file cannot know a session's
  password, so only shapes are redacted there.
