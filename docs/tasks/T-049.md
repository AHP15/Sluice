## T-049: Credit-based backpressure protocol for streamed row batches

- **Status**: done
- **Size**: M
- **Implements**: D-010
- **Mitigates**: R-006
- **Depends on**: T-010
- **Acceptance**: The core emits a row batch only against outstanding credit acknowledged by the webview, in-flight batches are bounded by a small fixed count, credit is returned as the virtualized grid retires rows, and cancellation and the statement timeout remain reachable while the stream is blocked on credit.

- **Notes**: Nothing streamed before this — browse and scripts returned
  whole results. Now structured browse streams: `PgDriver::browse_batches`
  reads incrementally (`query_raw`) and calls `emit` per batch (columns first,
  100 rows each), awaiting it, so the server cursor advances only as `emit`
  allows; `false` stops the stream, sends the **protocol cancel request** so the
  server stops too, and releases the lease (clean — no transaction involved).
  The app-layer `CreditGate` starts with `MAX_IN_FLIGHT` = 4 credits; each sent
  batch spends one; `grant_stream_credit` returns only credit for batches in
  flight, so the webview cannot inflate it. `cancel_stream` closes the gate,
  waking a producer blocked on credit at once, and the wait races the stream
  deadline (`STREAM_DEADLINE`, 300 s — T-051 owns the per-profile statement
  timeout value; this task guarantees it is honoured *while blocked*). The UI
  (`RowStream`) returns one credit per batch from an effect that runs after the
  batch has been committed to the grid's state, binding production to render
  rate; a superseded or closed tab cancels its stream, and credit owed before
  the stream id arrives is granted when it does. Verified against Postgres: a
  5000-row stream with no credit returned stops at exactly 4 batches, stays
  blocked (not finished), ends within the timeout once cancelled, reports 400
  delivered rows, and the pool connection serves the next browse. Unit tests
  cover the bound, one-for-one release, the inflation guard, cancel-while-
  blocked and deadline-while-blocked. The UI half was type-checked and built,
  not driven in the running app. Scope: browse only — raw scripts' multi-result
  streaming and the spill buffer are T-050/T-052; streaming is an inherent
  `PgDriver` method, to move into the `Driver` trait with the second engine.
