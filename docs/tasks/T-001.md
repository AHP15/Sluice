- **Notes**: Cargo workspace at the repo root with `src-tauri` as its member;
  builds clean to `target/debug/sluice` (Mach-O arm64) on tauri 2.11.5, and the
  frontend builds via `bun run build`. Scaffolded under the new name from the
  start rather than renaming afterwards (see T-003). No JS runtime ships: no
  sidecar and no `externalBin`, Bun appears only as package manager and Vite
  driver, and `frontendDist` is static assets. Verified `cargo tree` links zero
  database crates in the app today, which is the invariant T-007 must preserve.

  D-003 forbids `panic = "abort"` and T-006's `catch_unwind` only works while
  panics unwind; and the workspace `exclude = ["spikes"]` keeps the throwaway
  spike crates from contributing to the shipped lockfile.
