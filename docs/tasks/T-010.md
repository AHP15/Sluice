- **Notes**: `OutcomeBody` has exactly D-029's four variants — `rows`, `affected`,
  `status`, `error` — and every execution returns an ordered sequence of them.
  `ExecutionResult::single_rows` is the browse path, asserted to produce exactly
  one `rows` outcome. Verified live: a three-statement script returns
  Affected/Rows/Affected in order. R-020 is retired — DDL, affected counts and
  multiple result sets are all first-class rather than squeezed into a rows
  envelope. `Affected` also carries `concurrency_omitted` (T-073 F-4) and
  `document_errors` (T-066), so a weakened guarantee or a partial write is
  declared rather than silent.
