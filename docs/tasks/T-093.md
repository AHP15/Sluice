- **Notes**: App-level sidebar, always visible beside every tab. It lists every profile in the portable file by name, with an engine mark (PG/MS/MG, full name in the accessible label) and connection state. State is a filled or hollow dot plus label: being connected is not a safety guarantee, so it uses no D-032 status hue. Clicking switches to the profile tab if one is live; otherwise it opens a tab seeded with the profile that connects at once, reusing an idle blank tab. Power disconnects by closing the tab, which releases the session and the editor. Tabs report their session profile (session id prefix) to the shell, and tab titles follow the profile current name. A failed sidebar connect shows the error, a Retry, and the connect form opened on that profile for password re-entry (T-071), the only case the form is needed. 2026-11-07 (owner feedback): navigator merged into the panel. A connected row expands into its tab Navigator (portal into a slot under the row), and live unsaved sessions get rows too. The per-tab navigator aside and the inline connect form are gone; create, edit, import and delete happen in ConnectionDialog (modal). A failed connect offers Retry and Edit connection, and opens the dialog for password re-entry automatically when the core says so (T-071).
