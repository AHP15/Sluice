- **Notes**: Grid is headless TanStack Table + TanStack Virtual, exercised
  against 5,000 placeholder rows so the windowing is real rather than nominal
  (D-010 makes virtualization mandatory). Editor is a thin hand-rolled
  CodeMirror 6 wrapper rather than a React binding package, keeping the
  dependency surface small. TanStack Query owns core-sourced data and Zustand
  owns local UI state, with retry disabled because silently retrying a database
  call is the wrong default. One judgment call worth recording: **Tailwind v3,
  not v4** — v4 emits `@property`, `color-mix()` and cascade layers, all above
  the WebKitGTK 4.1 floor D-023 tells us to target, so v4 would have violated
  this task's own acceptance. The floor claim is enforced rather than asserted:
  `scripts/check-css-floor.mjs` fails the build on subgrid, color-mix, @property,
  oklch/oklab, :has(), @container, text-wrap:balance and anchor positioning, and
  runs as part of `bun run build`. Verified passing on the real emitted CSS, and
  verified the check actually fires by injecting a `subgrid` rule as a negative
  control. Grid spacer rows are plain `<tr>` heights rather than transforms,
  since transforms inside table layout behave inconsistently on older WebKit.
  2026-11-06: **reopened and re-landed.** `reconcile-status` found the grid
  did not use TanStack Table: `ResultGrid.tsx` (renamed from `DataGrid.tsx`)
  used TanStack Virtual over a hand-rolled table with fixed 180px columns,
  and `@tanstack/react-table` was installed but never imported. Owner chose
  to wire it in rather than revise D-023. The grid now builds column
  definitions from the core's `ColumnDesc` (positional ids, since a script can
  return duplicate column names), virtualizes TanStack's row model, and sizes
  and resizes columns through the model (`columnResizeMode: "onChange"`) —
  the groundwork staged edits, selection and server-driven sort will use.
  Rendering stays text-node-only (T-021). `tests/unit/resultGrid.test.tsx`
  server-renders it: one header per descriptor including duplicates, a resize
  handle per column, model-driven widths, and a hostile column name escaped.
  The virtualized body is not exercised by a server render; T-070 owns
  component tests in a DOM.
