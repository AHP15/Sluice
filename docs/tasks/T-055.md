- **Notes**: At connect, seven single-row probes (schemas, relations, columns, indexes, partitioning, materialized views, pg_stat views) each read the catalog objects the matching navigator query uses, and the successes are recorded in Capabilities.catalog. An unrecognized banner stays Flavour::Unknown internally but is displayed as `vanilla, unverified`, with flavour_verified = false. The navigator skips an area whose probe failed and puts a note in its place (a relation's columns still render when its indexes cannot). render_around turns catalog-divergence SQLSTATEs from our fixed queries (42P01, 42703, 42883, 42704) into a 'catalog differs here' note rather than an error. The UI shows a note above the tree at connect when the flavour is unverified or any area is missing. Live test: a real server probes fully and verified; with indexes, then relations, forced unavailable via a test-only with_catalog, navigation is partial with notes and never errors.
