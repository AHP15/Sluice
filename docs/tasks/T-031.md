- **Notes**: Scrub is a denylist over the app's own additions (`SLUICE_*`,
  plus `TAURI_*` — the Tauri CLI and CI set these, including
  `TAURI_SIGNING_PRIVATE_KEY`), never an empty environment; the user's shell
  env and the project `.env` reach the config, shell winning a conflict. A
  user-exported `PGPASSWORD` deliberately survives — their terminal would pass
  it too. Env is read with `vars_os`, since `vars()` panics on one non-UTF-8
  variable. Both pipes are drained concurrently, so a config logging past the
  ~64 KiB pipe buffer reports its real error instead of a false `TimedOut`.
  Display-before-connect is enforced by type: `UnconfirmedTarget` releases the
  URL only through `confirm(TargetDecision)`; `NativeTargetConfirmation` is the
  dialog (host/port/database, no password). The dialogs are not yet called —
  wiring is T-026's launcher. Known edge: a config that leaves a background
  grandchild holding stdout open yields `NoUrlInOutput` after a 2s grace rather
  than hanging. New risk for red-team/triage: a GUI launched from Finder/Dock
  gets launchd's environment, not the user's shell env, so the R-032 failure
  recurs on that path unless T-026's launcher always starts from a shell.
