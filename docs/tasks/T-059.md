- **Notes**: Originals (and every other bound edit or filter value) are bound
  as text and cast explicitly to the column's own type, as resolved from its
  OID by the prepared probe: `($n)::text::<target>`, never left to inference.
  `cast_target` now schema-qualifies and quotes every non-`pg_catalog` type,
  so an enum or domain outside the search path, or one shadowed by a
  same-named type earlier in it, casts to the right type. It quotes the
  one-byte `"char"`, since bare `char` means `bpchar(1)`, and builds array
  targets from the element type. The text cast was kept rather than binary
  binding. The corpus now runs a fourth check per type through `apply_edits`:
  the unmodified row and the NULL row (NULL original) commit, a row changed
  behind the edit's back conflicts, and types not declared comparable commit
  on the key with `v` in `concurrency_omitted`. 70 cases, 461 checks, 0
  failures against PG 17. Reverting `cast_target` to the bare name makes the
  new enum case fail with `operator does not exist: type_corpus.mood = mood`.
