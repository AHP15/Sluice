- **Notes**: `Navigator.tsx` contains no database/schema/table hierarchy: it reads node
  kinds from the capability descriptor and asks each only two questions — can it
  have children, can it be browsed. An undeclared kind still renders, as a leaf,
  which is D-029's "degrade gracefully on variants it does not recognise".
  Postgres declares `schema`/`table`/`view`/`matview`; the live test asserts the
  tree emits only kinds the descriptor declared, so a driver cannot smuggle an
  unrenderable kind past the contract. Catalog schemas are filtered out. This is
  the design T-073 F-6 validated as the contract's strongest point — the same
  component takes Mongo's two-level `database -> collection` tree with no
  placeholder node. Not visually verified: the app boots and registers its
  commands, but macOS screen-recording permission blocked capturing the rendered
  window, so the claim rests on the component typechecking against the real
  contract types plus the driver-side live test.
