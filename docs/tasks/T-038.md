- **Notes**: Profile entries carry `transport` (direct | ssh-tunnel | proxy) and `auth` (static | keychain | env | iam-token), both omitted from the file at their defaults (direct, keychain). The key is `auth` rather than `credential` so the existing IPC boundary test, which bans the word in any metadata JSON, stays strict. Field-less variants are empty struct variants because serde's internally-tagged unit variants accept stray keys; with deny_unknown_fields a `password` beside a provider is a parse error. Only `direct` transport connects; non-direct transports are refused with the ssh -L workaround. Providers implemented: keychain (existing) and env (Secret-wrapped at read, R-017). `static` and `iam-token` are modelled but refuse to connect: D-008 names `static` without defining it, so its semantics were left for a decision rather than invented here.
