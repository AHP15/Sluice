- **Notes**: Rows stream from the server cursor into a core-side writer and are never sent to the webview; the file is written as `.part` and renamed only when complete. A browse export runs the browse's filter and sort as one unbounded statement with the value ceiling lifted. A raw export re-runs exactly one statement (the server's `prepare` decides that, not the R-040 splitter) inside a rolled-back READ ONLY transaction, and is unavailable for multi-statement scripts and pinned editor sessions, with the reason shown. SQL INSERT uses untyped Postgres literals; a live test confirms an exact replay of numeric, bytea, jsonb, arrays, NaN and backslashes.
