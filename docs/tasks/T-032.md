- **Notes**: (1) **Text**: `blast_radius_for(os, sandboxed, file_fallback)` is
  a pure function, tested for every combination on every host. Linux without a
  sandbox states full privileges including the login keyring (and the
  encrypted-file passwords when present) and names bubblewrap as the fix;
  sandboxed Linux states keyring and saved passwords are withheld; macOS and
  Windows keep the per-app keychain claim but no longer claim the
  encrypted-file fallback is out of reach when it holds material. The
  launcher derives `sandboxed` from the same `probe_sandbox` result the
  evaluator acts on, so the dialog cannot promise isolation that is not
  applied. (2) **Sandbox**: `bwrap` from absolute system paths only (never
  `PATH`, as with the interpreter), probed by running it once on `/bin/sh -c :`
  — present-but-broken (no unprivileged user namespaces) degrades to the
  accurate warning rather than failing every evaluation. Withheld:
  `$XDG_RUNTIME_DIR` (session bus socket and gnome-keyring control socket) via
  tmpfs, a bus socket elsewhere via a `/dev/null` bind, an *abstract* bus via
  `--unshare-net` (the only way — abstract sockets are per network namespace),
  and `DBUS_SESSION_BUS_ADDRESS` unset. The rest of the filesystem stays bound
  read-write, because R-032: the config must see what the terminal sees.
  (3) **Key material**: the encrypted-file fallback keeps its key beside the
  ciphertext (D-007), so `<data_dir>/sluice` — key, ciphertexts and the consent
  store — is covered with tmpfs; a config therefore also cannot grant itself
  consent. In-memory secrets never reach the child: the env is denylisted
  (T-031) and std opens every fd close-on-exec. **Verified on Linux** in a
  `rust:1-bookworm` container as a non-root user with real bubblewrap and
  Node 22: the sandboxed config saw the bus variable, bus socket and key file
  all hidden; its no-sandbox control saw all three; and a mutant that skipped
  hiding the data dir failed on exactly `key_visible`. Locally on macOS the
  test compiles and skips. CI installs bubblewrap and fails the step if the
  test skips. Not done: Flatpak/Snap detection — R-033 notes they sandbox the
  *app*, which does not by itself withhold the bus from the app's child.
