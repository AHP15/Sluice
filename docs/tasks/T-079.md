## T-079: Build each session's driver from its engine at connect time

- **Status**: done
- **Size**: M
- **Implements**: D-003, D-022

- **Acceptance**: Connect resolves the profile's engine to a driver constructor through one factory that also builds the engine-specific connect spec and credential lookup, so adding an engine is one factory arm plus its crate, and an engine missing from the build reports a named error rather than falling through to Postgres.

- **Notes**: One factory (`engines::connect`) builds the engine-specific connect spec from an engine-neutral `Target`. `engines::lookup_credential` does the per-engine credential lookup (all engines share the provider resolution today). Both profile connect and launch connect go through it. SQL Server and MongoDB return "<Engine> connections are not available in this build" until their crates land: T-080 adds an arm, T-087 another. Test helpers connect through the factory too (`engines::test_postgres`).
