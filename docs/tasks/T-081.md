- **Notes**: Tree: database -> schema -> table | view -> column | index, read from sys.* views (never INFORMATION_SCHEMA) through three-part names, one level per expand, cached until refresh (notices never cached). Catalog areas are probed at connect with TOP 0 queries, including a `cross_database` probe ([master].sys.objects). Where cross-database references are refused (Azure SQL Database, error 40515), the tree shows only the current database plus a note; this comes from the probe, not EngineEdition. HAS_DBACCESS hides databases the login cannot open. Permission errors (229/916/...) and catalog divergence (207/208/40515) render as notes (D-016). Same dependency override as T-080.
