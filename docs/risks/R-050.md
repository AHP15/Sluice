## R-050: D-037's harmlessness test misses parameters some servers require, such as `retryWrites=false`

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: fix
- **Date**: 2026-11-07
- **Date resolved**:
- **Description**: D-037 ignore-lists a parameter if dropping it cannot change where Sluice connects, who it authenticates as, or how strongly TLS is verified, and names `retryWrites` as an example. Amazon DocumentDB and Azure Cosmos DB for MongoDB do not support retryable writes and their stock connection strings carry `retryWrites=false`; ignoring it leaves the driver's default (`true`) in place, and every staged edit then fails with a server error. The criterion covers routing, identity and TLS but not whether operations succeed.
- **Disposition rationale**: Medium severity at medium likelihood, but it shows D-037's admission criterion is wrong rather than its list incomplete, so the criterion is restated.
- **Action**: Superseded by D-041
- **Related decisions**: D-037, D-033
