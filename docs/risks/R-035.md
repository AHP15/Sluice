## R-035: The concurrency-comparable exclusion list covers enough real columns to hollow out the guarantee

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: mitigate
- **Date**: 2026-07-31
- **Description**: Excluding types with no usable equality sounds narrow but enumerates to `json`, `xml`, floating point, arrays, composites, domains, and every extension type the driver cannot vouch for -- and a driver deciding comparability from a static allowlist rather than probing `pg_operator` will exclude conservatively. A modern Postgres table with a `jsonb` payload and a `double precision` measurement drops to primary-key-only protection on most edits, so the lost-update window the decision exists to close is open on a large fraction of real tables. The UI advisory that says so appears often enough to become furniture the user stops reading.
- **Disposition rationale**: Medium severity at high likelihood, and the premise that drives it is partly wrong in a useful direction: `jsonb`, `citext`, arrays of comparable elements, and most extension types *do* have working equality — only `json`, `xml`, and a few others genuinely lack it. A static allowlist is what would hollow out the guarantee; asking the catalog does not.
- **Action**: Guard: determine comparability by probing the catalog rather than from a hardcoded list — a type is concurrency-comparable if `pg_operator` exposes a usable `=` for it (equivalently, a default btree or hash opclass in `pg_opclass`), resolved once per connection and cached in the capability descriptor. That keeps `jsonb`, `numeric`, `uuid`, `citext`, enums, domains over comparable base types, and arrays of comparable elements fully protected. For the genuinely non-comparable remainder, offer an opt-in `compare rendered form` mode (`col::text IS NOT DISTINCT FROM $1`) where the text output is stable, so protection degrades to comparing what the user actually saw rather than vanishing. Surface the reduced protection per affected edit at preview time rather than as a standing banner, so it stays information rather than furniture. Mitigating tasks: T-060.
- **Related decisions**: D-027, D-006
